# Apple Notes Habit Tracker Template

This is the Apple Notes version of Dominic Hart's "sanctuary habit tracker"
(from the video *"This book changed my life."*). Apple Notes can't draw the
sleep graph and its tables are basic, so this template approximates the system —
if you want the full experience (tappable grid + auto-drawn sleep graph), use the
**Watcher** web app in this repo instead (`index.html`).

## How the system works (30 seconds)

Every **morning**, you revisit **yesterday**:

1. Write **one line** about a memorable moment from yesterday.
2. Mark your habits: ✓ did it, ✗ didn't.
3. Log your sleep hours (and sleep score if your watch gives one).

Habits come in three kinds:
- **Non-negotiables** — you do these no matter what (e.g. weight check, cold exposure, exercise).
- **Building** (blue in the video) — habits you're working toward; missing one is okay.
- **Avoid** (red in the video) — bad habits you're tracking to drop (e.g. social media upon waking).

Plus: **3 realistic goals** for the month, a **"next month"** parking lot for habits
you'll add later, and a **half-page daily journal** ending with **3 gratitudes**.

## Setup (once per month, ~5 minutes)

1. In Apple Notes, create a folder called **Habit Tracker**.
2. Create a note per month. Copy the template below into it and rename the
   month/year.
3. For the habit grid: put the cursor on the "HABIT GRID" line, tap the
   **table button** (⊞) in the toolbar, and build a table with a **Day** column
   plus one column per habit, and **Sleep h** / **Score** columns at the end.
   Add a row per day of the month. (Apple Notes tables have no checkboxes —
   type `✓` or `✗` in the cell; leave blank for "not yet".)
4. Pin the note for the current month.

## What Apple Notes can't do (and where Watcher can)

| Feature from the video | Apple Notes | Watcher app |
|---|---|---|
| Habit grid with ✓/✗ | Manual table, typed symbols | Tap to cycle ✓ → ✗ → blank |
| Color-coded habit categories | No (plain text only) | Yes (black/blue/red) |
| Sleep graph (hours per day) | **Not possible** — log numbers only | Drawn automatically |
| Sleep score | Number in a cell | Logged + shown on hover |
| Monthly stats (totals, averages) | Manual | Automatic |
| Monthly rollover with your habits | Copy-paste the note | Automatic |
